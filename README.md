# Котик Штрих

Бесплатные уроки рисования для детей: ребёнок рисует на бумаге, Штрих показывает каждый штрих на экране и озвучивает шаги.
5 уровней, 40 техник, 155 рисунков, 10 языков. Без рекламы, без сбора данных.

## Что где лежит

```
www/                 само приложение (обычная веб-страница, без сборщиков)
  index.html         разметка и стили
  config.js          ← ВАШИ НАСТРОЙКИ: реквизиты, подпись, почта
  js/                уроки (lessons-*.js), геометрия рисунков, интерфейс (app.js)
  i18n/              переводы на 9 языков (русский — основной, в самом коде)
  icons/, fonts/     иконки и (по желанию) локальные шрифты
  privacy.html       политика конфиденциальности (нужна магазинам)
tools/
  build.py           собирает версии в dist/ (web, telegram, rustore, store, preview, app:*)
  make_icons.py      рисует иконки, заставки и картинки для магазинов
  build_i18n.py      собирает переводы из tools/tr/*.txt в www/i18n/*.js
  export_phrases.js  выгружает все фразы для озвучки в tools/phrases/
  make_voice.py      генерирует нейро-озвучку (Azure / Яндекс SpeechKit / edge-tts)
  get_fonts.sh       скачивает шрифты Neucha и Nunito в www/fonts
  capacitor_setup.sh создаёт Android- и iOS-проекты (Capacitor)
  patch_native.py    портретная ориентация и доступ к синтезу речи в нативных проектах
store/               иконки 1024/512, баннер 1024×500, картинка для BotFather, тексты карточек (listing.md)
resources/           исходники иконки и заставки для Capacitor
```

## Частые команды

```bash
python3 tools/build.py                 # все версии в dist/
python3 tools/build.py web telegram    # только сайт и Telegram
npm run app:store                      # пересобрать мобильное приложение для App Store / Google Play
npm run app:rustore                    # то же для RuStore (с кнопкой «Поддержать»)
python3 tools/build_i18n.py            # после правки переводов в tools/tr/
node tools/export_phrases.js           # после правки текстов уроков — перед генерацией озвучки
```

## Версии и пожертвования

| Версия | Кнопка «Поддержать разработчика» | Почему |
|---|---|---|
| web, telegram, rustore | есть, за «родительским замком» | ссылка на перевод с карты + адреса криптокошельков |
| store (App Store, Google Play) | нет, только тёплое сообщение «бесплатно и без рекламы» | правила магазинов: оплата и чаевые — только через их встроенные покупки, внешние ссылки на оплату запрещены |

Реквизиты меняются в одном месте — `www/config.js`. Сборщик предупредит, если там остались примеры.

## Голос

1. Если есть файлы `www/audio/<язык>/*.mp3` (их делает `tools/make_voice.py`) — звучит живой нейро-голос.
2. В мобильном приложении — системный синтезатор через плагин `@capacitor-community/text-to-speech`.
3. В браузере — лучший голос устройства (родитель может выбрать в разделе «Для взрослых»).

Подробная инструкция по публикации — в отдельном документе.
